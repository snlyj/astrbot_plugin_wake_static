# astrbot_plugin_wake_static

**免 @ 唤醒插件** —— 在群里喊一句「静」，机器人立刻应答，不再需要 @ 它。

## 功能

- **免艾特唤醒**：主人（指定用户）在群聊中发出的消息只要包含唤醒词「静」，无论在句首、句中还是句尾，都会被标记为唤醒消息，机器人立即回复；
- **接话窗口**：唤醒后 120 秒内，该会话中主人的后续消息即使不带唤醒词也会被放行，保持连续对话体验；
- **主人专属**：只有配置的主人 ID 能触发唤醒，其他群成员喊破喉咙机器人也不理（配合 `astrbot_plugin_exclusive_master` 使用效果最佳）；
- **自动 GC**：会话窗口字典超过 256 条时自动清理过期项，长期运行零泄漏。

## 安装

```bash
# 方式一：克隆到 AstrBot 插件目录
cd /path/to/AstrBot/data/plugins
git clone https://github.com/snlyj/astrbot_plugin_wake_static.git
# 重启 AstrBot 或在 WebUI 面板热重载
```

## 配置

### MASTER_ID（必填）

主人的平台用户 ID（如 QQ 号）。

**方式一：环境变量**

```bash
export ASTRBOT_MASTER_ID="你的QQ号"
```

**方式二：直接改代码**

编辑 `main.py` 第 8 行：

```python
MASTER_ID = "你的QQ号"
```

> 查看自己的 ID：给机器人发 `/info`，或在 AstrBot WebUI 的消息记录中查看 `sender_id`。

## 参数说明（源码可调项）

| 参数 | 默认值 | 位置 | 说明 |
|------|--------|------|------|
| `MASTER_ID` | 无（必填） | 环境变量 `ASTRBOT_MASTER_ID` 或源码第 8 行 | 允许触发唤醒的用户 ID |
| `WAKE_WINDOW` | `120` 秒 | 源码第 11 行 | 唤醒后免唤醒词接话的窗口时长，可根据聊天节奏调大调小 |
| `_WINDOW_GC_THRESHOLD` | `256` | 源码第 17 行 | 会话窗口缓存条数阈值，超过则清理过期项，一般无需修改 |

## 使用

配置完成后无需任何指令：

```
你：静，今天天气怎么样        ← 包含「静」，唤醒并回复
你：那明天呢                  ← 120秒窗口内，直接接话
群友A：静静，你是谁           ← 不是主人，不触发唤醒
```

## 常见问题

**Q：唤醒词能改成别的字吗？**
可以，编辑 `main.py` 中 `filter` 方法里的 `if "静" in text:`，把「静」换成你机器人的名字。

**Q：为什么别人喊了没反应？**
这是设计如此——本插件只服务主人。如果想让所有人都能免 @ 唤醒，删除 `filter` 方法开头的主人校验那两行即可。
